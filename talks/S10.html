Cleaning and Structuring Historical Data: A Working Session

Jim Clifford (University of Saskatchewan)

Thursday, October 15, 2026, 1:30 to 2:30 Eastern, Room 110

Watch on YouTube

Abstract

Clifford walks through the pipeline behind the Imperial Careers Atlas, which maps the careers of British colonial officials, instead of running a hands-on workshop. The pipeline starts with optical character recognition (OCR) of the biographies printed in the Colonial Office List and the Indian Office List. A Python script splits the text into individual biographies and an open Qwen model converts each one to JSON, after which Python rules fix dittos and merge duplicate people. He then grounds places and people in Wikidata using an MCP (Model Context Protocol) server with vector search and QLever for deterministic matching, reaching 86 percent grounding for places. The discussion turns to cost and to how clean a dataset needs to be.
