Build Your First Software: A Historian's Introduction to Writing Code

Jeri Wieringa (Princeton University)

Thursday, October 15, 2026, 11:30 to 12:30 Eastern, Room 110

Watch on YouTube

Abstract

A beginner-friendly session on writing software for historical research, taught from a research software engineering (RSE) perspective. Jeri Wieringa shows how large language model (LLM) coding tools such as Claude change what it takes to build a research tool, using a live project that turns 19th-century statistical reports into a spreadsheet. The demonstration focuses on project folders and written plans, with version control handled in Git. She closes by showing how the same files can move into other tools such as VS Code.
