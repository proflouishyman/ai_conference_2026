Searching for Reliability: Using AI to Build Persistent Tools for Research in History

S. Wright Kennedy (University of South Carolina)

Friday, October 16, 2026, 11:30 to 12:30 Eastern, Room 108

Watch on YouTube

Abstract

Commercial AI platforms follow a predictable decay cycle, so a methods paper can rest on a model that no one can access. S. Wright Kennedy argues for building with AI rather than outsourcing to it, using locally run tools on data you control, with outputs that leave an auditable trail. His worked example is a desktop text mining and mapping tool built on Melissa Dell's reprocessed optical character recognition (OCR) of Chronicling America newspapers, demonstrated on coverage of the Haymarket affair. The talk asks what provenance means when the tools used to analyze the evidence no longer exist.
